# Codsoft-Intership

CODSOFT INTERSHIP DATA SCIENCE

Overview This repository contains the projects completed during my Data Science Internship at CODSOFT.

The internship provided an opportunity to apply Data Science and Machine Learning concepts to practical datasets. The projects covered different types of Machine Learning problems, including classification and regression.

As part of the internship requirements, a minimum of three tasks had to be completed. I successfully completed four tasks.

Internship Projects Task Project Problem Type Task 1 Titanic Survival Prediction Classification Task 3 Iris Flower Classification Classification Task 4 Sales Prediction Using Python Regression Task 5 Credit Card Fraud Detection Classification Task 1: Titanic Survival Prediction Objective The objective of this project was to build a Machine Learning model capable of predicting whether a passenger survived the Titanic disaster.

The dataset contains passenger information such as age, gender, ticket class, fare, cabin, and survival status.

Workflow Imported the dataset. Explored the structure and characteristics of the data. Performed data cleaning and preprocessing. Handled missing values. Prepared relevant features. Divided the dataset into training and testing sets. Trained a classification model. Generated predictions. Evaluated the model performance. Machine Learning Type Classification

Task 3: Iris Flower Classification Objective The objective of this project was to classify Iris flowers into their respective species using sepal and petal measurements.

The three species included in the dataset are:

Iris Setosa Iris Versicolor Iris Virginica The internship task specifically focuses on using sepal and petal measurements to classify the flowers.

Workflow Loaded the Iris dataset. Performed exploratory analysis. Examined the flower measurements. Prepared the input features and target variable. Split the dataset into training and testing data. Trained a classification model. Generated predictions. Evaluated the model. Machine Learning Type Multi-class Classification

Task 4: Sales Prediction Using Python Objective The objective of this project was to predict sales using factors related to advertising expenditure, target audience segmentation, and advertising platform selection.

The project demonstrates how Machine Learning can be used to analyze advertising-related data and support sales forecasting and business decision-making.

Workflow Loaded the dataset. Explored the available variables. Performed data preprocessing. Conducted exploratory data analysis. Identified relevant features. Divided the data into training and testing sets. Trained a regression model. Generated sales predictions. Evaluated the model performance. Machine Learning Type Regression.
